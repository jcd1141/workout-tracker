# workout-tracker
OOP workout tracking system

This Workout Tracker is an object Oriented Program that keeps track of and summarizes workouts. Users can write different kinds of workouts, along with the duration, and the tracker will calculate the calories burned.

This program demonstrates key concepts in OOP. Inheritance, Polymorphism, Encapsulation, and Composition. Exercise subclasses (CardioExercise, StrengthExercise, FlexibilityExercise) extend the base "Exercise" class, each exercise type overrides methods like calculate_calories() and get_duration(), the Workout class stores exercises in a private list and controls access through methods, and a workout object is composed of multile exercise objects.

This project allowed me to stregthen my understanding in OOP and its key concepts. it was certsainly challenging and I did have to call on a lot of recourses (my notes, videos, AI, etc) to help me better understand the project as a whole. Syntax, indetation, logic errors, all prevelant throughout. However I was able to use inheritance by creating multiple subclasses for the Exercise class which shared common behaviors while holding their own logic. I also practiced composition by building a Workout class that manages Exercise objects. Overall, the project helped reinforce how OOP design makes systems reusable and scalable.
